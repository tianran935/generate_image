## 二、实验变量设置

| 变量                    | 当前取值/变化方式                                                                                                | 画面表现                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `item`                | 从 SKU 表抽样，默认每次每类抽 8 个商品                                                                           | 商品身份、包装、品牌                       |
| `position`            | 固定 2x4 网格；改图时会随机打乱 8 个位置                                                                         | 第几行第几列                               |
| `price`               | 基础价格来自`gross_amt/item_qty`或`net_amt/item_qty`，否则`$3.99`；改图时`p' = p * logNormal(0, 0.3)`    | 货架价格牌                                 |
| `promotion`           | 默认`none`；改图时随机 1-4 个 SKU 变成`"Promotion"`                                                          | 促销标识                                   |
| `bestseller_badge`    | 默认`none`；改图时随机 1-4 个 SKU，从`热销`/`BEST SELLER`/`销量冠军`/`今日TOP1`中抽                    | 热销标签                                   |
| `inventory_remaining` | 当前库存档位为`[1,2,3,4,6,8,10,12]`；生图时打乱后分配给 8 个 SKU；改图时逐 SKU 随机抽一个档位                  | 用商品数量、空位、铺货宽度、纵深或堆叠体现 |
| `size`                | 按品类随机抽规格，如 chips:`7 oz`,`8.5 oz`,`9.25 oz`,`10 oz`,`13 oz`；改图时已有 size 保持，不存在才补 | 包装视觉大小                               |

## 四、程序入口

### 1. 生图模式

| SKU 字段                            | 初始来源/规则                 | 图上含义                         |
| ----------------------------------- | ----------------------------- | -------------------------------- |
| `sku_id`                          | CSV`upc_id`                 | 商品身份                         |
| `item`                            | CSV`upc_description`        | 商品名/包装识别线索              |
| `category_name`                   | CSV                           | 品类                             |
| `base_price`                      | `gross_amt / item_qty` 估算 | 原始基准价格                     |
| `price`                           | 初始等于`base_price`        | 货架价格                         |
| `promotion`                       | 默认`none`                  | 促销标识                         |
| `bestseller_badge`                | 默认`none`                  | 热卖/畅销 badge                  |
| `size`                            | 按品类随机常见规格            | 包装大小/规格                    |
| `flavor`                          | 从商品名规则推断              | 口味/款式                        |
| `weight`                          | 从`size`解析                | unit price/size rationality 计算 |
| `inventory_remaining（暂时忽略）` | 不传入 request                | 不表现库存差异                   |
| `position`                        | 2x4 固定顺序                  | 货架位置                         |
| `product_image`                   | 从参考图目录按 UPC 匹配       | 包装参考图                       |

| 参数                               |                                             默认值 | 作用                                        | 是否会影响图                |
| ---------------------------------- | -------------------------------------------------: | ------------------------------------------- | --------------------------- |
| `--mode generate`                |                                               必填 | 生图模式                                    | 是                          |
| `--category`                     |                                           所有类别 | 指定抽样品类，可重复或逗号分隔              | 是，决定 SKU 池             |
| `--sample-size`                  |                                              `8` | 每个品类抽几个商品                          | 是，当前货架设计主要按 8 个 |
| `--sample-count`                 |                                              `1` | 每个品类抽样次数                            | 是，决定生成多少张          |
| `--seed`                         |                                               随机 | 控制抽样、size、库存等随机值                | 是                          |
| `--catalog-file`                 | `data_clean/top_50_skus_selected_categories.csv` | SKU 数据源                                  | 是                          |
| `--product-image-dir`            |                                  `pic_reference` | 商品参考图目录，递归扫描                    | 是                          |
| `--reference-sheet-only`         |                                          `False` | 只传 PIL 合成的 2x4 参考图，不传 8 张单品图 | 是                          |
| `--allow-missing-product-images` |                                          `False` | 允许缺商品图时用文字线索生成                | 是                          |
| `--aspect-ratio`                 |                                            `4:3` | 输出比例                                    | 是                          |
| `--image-size`                   |                                             `1K` | 输出尺寸，可选`1K/2K`                     | 是                          |
| `--model`                        |                         `openai/gpt-5.4-image-2` | 图片模型                                    | 是                          |
| `--request-output-file`          |                                                 无 | 保存最终 request JSON                       | 否，只记录                  |
| `--output-file / --output-dir`   |                                                 无 | 输出图片位置                                | 否                          |

### 2. 改图模式

| 参数                               |            默认值 | 作用                              | 是否会影响图 |
| ---------------------------------- | ----------------: | --------------------------------- | ------------ |
| `--mode edit`                    |              必填 | 改图模式                          | 是           |
| `--input-image`                  |              必填 | 原始货架图                        | 是           |
| `--base-request-file`            |          推荐必填 | 复用原图的 SKU 和结构             | 是           |
| `--seed`                         |              随机 | 控制随机改动                      | 是           |
| `--promotion-count`              |     `1–4` 随机 | 指定几个商品显示 Promotion        | 是           |
| `--bestseller-count`             |     `1–4` 随机 | 指定几个商品显示 bestseller badge | 是           |
| `--product-image-dir`            | `pic_reference` | 商品参考图目录                    | 是           |
| `--reference-sheet-only`         |         `False` | 只传合成参考图                    | 是           |
| `--allow-missing-product-images` |         `False` | 允许无商品图 fallback             | 是           |
| `--aspect-ratio`                 |           `4:3` | 输出比例                          | 是           |
| `--image-size`                   |            `1K` | 输出尺寸                          | 是           |
| `--request-output-file`          |                无 | 保存 edit request JSON            | 否，只记录   |
| `--output-file / --output-dir`   |                无 | 输出图片位置                      | 否           |

| 可变变量             | 字段                    | 当前规则                                                                   |
| -------------------- | ----------------------- | -------------------------------------------------------------------------- |
| 位置                 | `position`            | 随机打乱 2x4 位置                                                          |
| 价格                 | `price`               | `base_price * logNormal(0, 0.3)`                                         |
| 促销                 | `promotion`           | 随机`1–4` 个商品设为 `Promotion`，或用 `--promotion-count` 指定数量 |
| 热卖标识             | `bestseller_badge`    | 随机`1–4` 个商品加热卖 badge，或用 `--bestseller-count` 指定数量      |
| 剩余库存（暂时忽略） | `inventory_remaining` | 随机库存水平，用可见商品数量/空位视觉表现                                  |
| size                 | `size`                | 当前主要保留原 size；若缺失则按品类补一个常见规格                          |
